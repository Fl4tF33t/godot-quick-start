# Godot Project Initializer

A Godot Editor addon that automates new project setup, including folder structure, project and editor settings, and addon installation.

## Features

- **Folder Setup** — Automatically create your project directory structure.
- **Project Settings** — Configure project settings to your preferences.
- **Editor Settings** — Apply preferred editor configurations.
- **Addon Installer** — Install third-party addons directly into your project.

## Installation

1. Clone or download this repository.
2. Place it inside your project's `addons` folder.
3. Enable it under **Project → Project Settings → Plugins**.

## Usage

Open the Project Initializer from the Godot Editor, configure your setup, and apply it to your project.

## Compatibility

- Godot 4.x
